Today's build

A profiling CLI: file in, profile out.

Input
Any of three formats
.csv .parquet .json
$ profile data.parquet
  -o profile.csv
Output — one CSV, one row per column
Each source column becomes a row.
column dtype count null_pct distinct top_value top_freq min max mean
distinct = cardinality. Numeric stats fall back to blank for text columns.
Small enough to finish in the session, real enough to run on our data afterwards.
Why Polars

Fast, typed, and reads all three formats out of the box.

One API
Three formats, one DataFrame
read_csv · read_parquet
read_json
Built for this
Lazy & multithreaded
Profiling a wide file stays quick.
Expressive stats
Most of the profile is one line
null_count · n_unique
value_counts · describe
Less glue code means more of the session spent on the workflow, not the plumbing.
